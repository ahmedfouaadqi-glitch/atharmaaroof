# متطلبات المنتج — أثَر V1

## النطاق
منصة عراقية آمنة للمفقودات والمعثورات، تبدأ ببغداد وكربلاء والنجف والبصرة وسامراء (مدينة ضمن محافظة صلاح الدين).

## الرحلات الأساسية
- تسجيل بلاغ فقدان أو عثور دون اشتراط صورة المستمسك.
- اختيار المدينة والمنطقة التقريبية؛ GPS اختياري.
- البحث عن بلاغات مرشحة للمطابقة.
- طلب استرجاع خاص ومتابعة التسليم.
- إغلاق الحالة بعد تأكيد الاسترجاع.

## المساعد
يفهم النية ويجمع الحقول غير الحساسة ويسأل عن النواقص. لا ينشر أو يرسل رسالة ذات أثر خارجي دون موافقة. درجة المطابقة ليست إثبات ملكية. لا يخترع إجراءات حكومية. لا يتلقى صور المستمسكات أو بيانات البطاقة المصرفية.

## الخصوصية
- لا صور Visa/Mastercard أو PAN/CVV/PIN/OTP.
- صور المستمسكات الرسمية ليست مطلوبة ولا تنشر للعامة.
- أرقام الهواتف خاصة افتراضياً، والموقع العام تقريبي.
- تخزين خاص وفحص ملفات وسياسة احتفاظ وحذف.
- التحقق من الصلاحيات على الخادم لكل سجل وعملية.
- لا نعتمد على تعطيل كلك يمين أو أدوات المطورين كضابط أمني.

## الصوت V1
جلسة يبدأها المستخدم صراحة، حد افتراضي دقيقتان، مؤشر وقت وإنهاء وكتم، ولا تحفظ التسجيلات الخام افتراضياً. مؤقت المتصفح وحده ليس فرضاً أمنياً؛ يلزم حد خادمي عند ربط مزود realtime voice. الصوت الحالي واجهة متصفح تجريبية وليس مكالمة هاتفية أو AI realtime مكتمل.

## لوحة الإدارة
مساحة مستقلة عن التنقل العام، MFA وRBAC وسجلات تدقيق وصلاحيات إقليمية. غير مطبقة في الواجهة الحالية.

## الحالة الحالية
الواجهة الأولية فقط. لا يوجد backend أو قاعدة بيانات أو مصادقة أو مطابقة خادمية. البلاغات تجريبية ومحلية.
