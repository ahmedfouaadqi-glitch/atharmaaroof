# أثر معروف

منصة عراقية للمفقودات والمعثورات، بواجهة عربية RTL سريعة ومتجاوبة للهواتف والأجهزة اللوحية والحواسيب.

## الهوية والتجربة
- شعار أصلي مستوحى من معنى «الأثر»: مسار آثار ينتهي بعلامة موقع، مع اسم «أثر معروف» كاملاً.
- أيقونة تطبيق مستقلة وملف شعار أفقي بصيغة SVG.
- مساعد بحث داخل حقل الصفحة الرئيسية.
- محادثة صوتية بالعربية عبر Web Speech API في المتصفحات الداعمة، مع إدخال نصي بديل وقراءة الرد عبر speechSynthesis.
- حركة Parallax للمجموعة البصرية عبر حساسات الجهاز، مع تحديث CSS مباشرة لتجنب إعادة رسم الصفحة.
- مؤثرات صوتية اختيارية ومفعلة افتراضياً، مع حفظ اختيار الكتم.
- رابط واضح للبحث القريب بعد موافقة المستخدم على مشاركة الموقع.
- لافتة تثبيت PWA وManifest وService Worker.
- إزالة طبقة Canvas العامة وتأثيرات Magnet غير الضرورية من المسارات الرئيسية لتقليل الحمل.

## هوية الزائر
يستطيع الزائر التصفح دون حساب، وتُنشأ جلسة Supabase Anonymous Auth عند فتح نموذج البلاغ. لا نستخدم IP أو MAC كبصمة هوية. الجلسة المجهولة مرتبطة بالمتصفح؛ إذا حُذفت بيانات الموقع أو غُيّر المتصفح/الجهاز فقد تُفقد، لذلك يلزم ربطها لاحقاً ببريد أو وسيلة دخول دائمة للاستعادة.

فعّل **Authentication → Providers → Anonymous Sign-Ins** في مشروع Supabase المقصود. فعّل CAPTCHA/Turnstile وراجع حدود Auth قبل الإطلاق العام للحد من إساءة استخدام الحسابات المجهولة.

## الموقع القريب
- لا يطلب التطبيق الموقع عند فتح الصفحة.
- المستخدم يضغط «البلاغات القريبة مني» للموافقة على مشاركة الموقع.
- إحداثيات جهاز الزائر تُستخدم لبحث واحد ولا تُحفظ في ملفه.
- إذا اختار المستخدم إضافة موقع إلى بلاغ، تُخزن إحداثيات تقريبية بدقة منزلتين عشريتين، ولا تظهر الإحداثيات للعامة.
- يتطلب ذلك تطبيق ترحيل 20261101000200_athar_nearby_reports.sql.

## الإدارة والصلاحيات
- بوابة الإدارة المنفصلة: /control-center.
- لا يوجد تسجيل مشرف من الواجهة.
- يتطلب الدخول بريد الخادم ATHAR_ADMIN_EMAILS، وجلسة Supabase Auth، وعضوية athar_admins.
- واجهات الإدارة تعيد التحقق من الصلاحية على الخادم.
- لا تحفظ كلمة مرور أو رمز دخول إداري في الكود أو المتصفح.

## المساعد والصوت
يبحث المساعد في athar_public_reports فقط. يمكن تفعيل صياغة إجابات عبر موفر OpenAI-compatible باستخدام ATHAR_AI_CHAT_COMPLETIONS_URL وATHAR_AI_API_KEY وATHAR_AI_MODEL على الخادم. عند غياب الإعداد يستخدم البحث الموجّه ولا يدّعي أنه نموذج توليدي.

المحادثة الصوتية تستخدم التعرف الصوتي الذي يوفره المتصفح؛ قد يختلف الدعم والمعالجة باختلاف Chrome/Edge/Safari والجهاز. لا يخزن التطبيق ملف تسجيل صوتي، ويتلقى النص الناتج للتعرف الصوتي. قراءة الرد تعتمد على صوت الجهاز.

## سياسات المنصة
- /privacy: سياسة الخصوصية.
- /terms: شروط الاستخدام.
- /faq: الأسئلة الشائعة.
- /about: عن المبادرة وصاحبها.

محتوى الشروط والخصوصية معلومات تشغيلية أولية وليست استشارة قانونية؛ يجب مراجعتها قانونياً قبل الإطلاق الرسمي.

## إعداد الخدمة
تحتاج الوظائف الفعلية إلى ضبط متغيرات Vercel:
- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
- ATHAR_ADMIN_EMAILS (قائمة بريد إداري من جهة الخادم فقط)

لا تستخدم service_role في متغير يبدأ بـ NEXT_PUBLIC_، ولا ترفع الأسرار إلى Git.

## Supabase migrations

تُطبق الترحيلات بالترتيب:

1. supabase/migrations/20261031000100_athar_reports.sql
2. supabase/migrations/20261101000100_athar_security_hardening.sql
