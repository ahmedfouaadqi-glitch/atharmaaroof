# أثَر | ATHAR

منصة عراقية ذكية وآمنة للمفقودات والمعثورات.

واجهة Next.js أولية عربية RTL، مع تفاعلات مستلهمة من React Bits.

## الحالة الحالية
هذه مرحلة تأسيس الواجهة. لم يُربط backend أو قاعدة بيانات أو تسجيل دخول أو مطابقة خادمية أو لوحة إدارة فعلية. البلاغات التجريبية لا تُنشر على الخادم. واجهة الصوت الأولية بحد أقصى دقيقتين، وليست مكالمة هاتفية أو محادثة AI آنية متكاملة.

## التشغيل
`npm install` ثم `npm run dev`

## المراجع
https://reactbits.dev/
https://github.com/DavidHDev/react-bits

## طبقة الخادم — بداية V1

أُضيفت الآن نقطة دخول الحسابات `/login`، وواجهات `/api/auth` و`/api/reports`، وملف ترحيل قاعدة بيانات Supabase مع RLS وواجهة عرض عامة لا تتضمن معرّف صاحب البلاغ.

**هذه الملفات لا تعني أن قاعدة البيانات تعمل بالفعل.** يلزم ربط مشروع Supabase مخصص لأثَر، وتطبيق ملف الترحيل، وإعداد متغيرات البيئة ومزوّد البريد، ثم اجتياز CI واختبارات تكامل فعلية. لا تستخدم مشروعاً يعود لتطبيق آخر.

راجع `docs/BACKEND_SETUP.md` للتشغيل وحدود الأمان. لا تُدخل أرقام المستمسكات أو بيانات البطاقة المصرفية أو OTP أو إحداثيات GPS الدقيقة.
